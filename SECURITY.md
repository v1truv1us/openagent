# Security Policy

## Reporting a Vulnerability

**Email:** security@v1truv1us.dev

Please do not open public issues for security vulnerabilities.

## Scope

- LLM provider abstraction credentials
- Agent runtime sandbox escape
- Memory storage data leakage
- Workflow execution injection

## Timeline

- Acknowledgment: 48h
- Assessment: 7 days
- Fix: 90 days target
